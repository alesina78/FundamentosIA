# Módulo 4 — Agentes de IA e Tool Use

> Nível: Intermediário · O módulo em que o modelo deixa de só gerar texto e passa a agir.

## Objetivos de Aprendizagem

Ao final deste módulo, você será capaz de:

- Implementar function calling / tool use com a API da Anthropic em Python.
- Construir um loop agentic simples (padrão ReAct: raciocinar → agir → observar).
- Entender os trade-offs de sistemas multi-agente vs um único agente com várias ferramentas.
- Identificar riscos de agentes autônomos (loops infinitos, ações irreversíveis, custo).
