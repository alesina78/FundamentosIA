# Módulo 6 — SDD (Spec-Driven Development)

> Nível: Intermediário · Carga horária: ~3h

## Objetivos de Aprendizagem

Ao final deste módulo, você será capaz de:

- Explicar o que é Spec-Driven Development e por que ele funciona melhor com IA do que
  "vibe coding" sem estrutura.
- Escrever uma especificação clara o suficiente para guiar um agente de codificação.
- Aplicar um fluxo spec → plano → implementação → verificação num projeto real.
- Reconhecer os riscos de pular a etapa de spec (retrabalho, escopo mal definido).
