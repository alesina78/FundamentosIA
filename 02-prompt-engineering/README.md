# Módulo 2 — Prompt Engineering

> Nível: Iniciante · Base para todos os módulos seguintes — RAG, agentes e harness são
> prompt engineering aplicado.

## Objetivos de Aprendizagem

Ao final deste módulo, você será capaz de:

- Estruturar prompts claros com instrução, contexto, exemplos e formato de saída.
- Aplicar few-shot prompting e chain-of-thought para melhorar a qualidade das respostas.
- Escrever system prompts eficazes e controlar o formato de saída (ex: JSON estruturado).
- Depurar um prompt que está gerando resultados ruins ou inconsistentes.
- Medir a qualidade de um prompt com um eval, em vez de julgar "no olho".
