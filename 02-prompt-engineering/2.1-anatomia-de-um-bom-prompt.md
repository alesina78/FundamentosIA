# 2.1 — Anatomia de um Bom Prompt

> **Prompt**: a entrada de texto (instrução, contexto, exemplos, formato desejado) que
> você envia a um LLM para obter uma resposta.

## Os quatro componentes de um prompt eficaz

Um prompt vago produz uma resposta vaga. Um bom prompt geralmente combina:

1. **Instrução** — o que você quer que o modelo faça, em um verbo de ação claro
   ("resuma", "classifique", "gere", "compare").
2. **Contexto** — informação de fundo que o modelo não tem por padrão (dados do seu
   negócio, restrições, público-alvo).
3. **Exemplos** (opcional, mas poderoso — ver aula 2.2) — mostrar o padrão esperado em
   vez de só descrevê-lo.
4. **Formato de saída** — como a resposta deve ser estruturada (lista, JSON, tabela,
   limite de tamanho).

## Prompt fraco vs. prompt forte

| | Prompt fraco | Prompt forte |
|---|---|---|
| Instrução | Implícita ou genérica | Verbo de ação específico |
| Contexto | Ausente | Presente e relevante à tarefa |
| Formato | Não especificado | Explícito (lista, JSON, tamanho) |
| Resultado | Resposta genérica, pode divagar | Resposta direcionada e utilizável |

```
❌ "Escreva sobre marketing."
✅ "Você é consultor de marketing para pequenas empresas. Contexto: uma cafeteria
   quer aumentar o movimento às terças e quartas. Sugira 3 ações de baixo custo,
   específicas. Formato: lista numerada, 2 frases por item."
```

## Exemplo em Python — comparando as duas abordagens

Código completo: [`exemplos-python/2.1_prompt_fraco_vs_forte.py`](exemplos-python/2.1_prompt_fraco_vs_forte.py)

```python
def perguntar(prompt: str) -> str:
    r = client.messages.create(
        model="claude-haiku-4-5",
        max_tokens=300,
        messages=[{"role": "user", "content": prompt}],
    )
    return r.content[0].text
```

Rode o script e compare as duas saídas: o prompt forte tende a produzir uma resposta mais
curta, específica e imediatamente utilizável — o fraco tende a ser genérico e pode não
respeitar nenhum formato.

## Pontos-Chave

✅ Instrução + contexto + formato de saída são a base de um prompt eficaz.
✅ Ser específico reduz a chance do modelo "preencher lacunas" com suposições erradas.
✅ Definir o formato de saída explicitamente evita ter que reprocessar a resposta depois.
✅ Um prompt vago quase sempre produz uma resposta vaga — a especificidade é sua responsabilidade.
