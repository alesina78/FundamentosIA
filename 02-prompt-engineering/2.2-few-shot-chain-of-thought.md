# 2.2 — Few-Shot e Chain-of-Thought

> **Few-shot prompting**: mostrar ao modelo alguns exemplos do padrão de entrada/saída
> esperado, em vez de apenas descrever a tarefa em palavras.
>
> **Chain-of-thought (CoT)**: instruir o modelo a expor o raciocínio passo a passo antes
> de dar a resposta final, o que geralmente melhora a precisão em tarefas que envolvem
> lógica, matemática ou múltiplas etapas.

## Zero-shot vs. few-shot

| | Zero-shot | Few-shot |
|---|---|---|
| O que você fornece | Só a instrução | Instrução + exemplos de entrada→saída |
| Quando usar | Tarefas simples e comuns | Tarefas com formato específico, ambíguas, ou fora do padrão |
| Vantagem | Prompt curto | Modelo "aprende" o padrão pelo exemplo, não pela descrição |
| Custo | Menor (menos tokens) | Maior (exemplos consomem tokens de input) |

Few-shot é especialmente útil quando é mais fácil **mostrar** o formato exato que você
quer do que **descrevê-lo** em palavras — por exemplo, um formato de classificação
específico do seu domínio.

## Chain-of-thought: por que funciona

Um LLM gera token a token (aula 1.1) — ele não "pensa antes de escrever" a menos que você
peça. Ao instruir "pense passo a passo", você força o modelo a gerar os passos
intermediários do raciocínio como texto, o que ele então usa como contexto para chegar à
resposta final. Isso reduz erros em tarefas de matemática, lógica e problemas com múltiplas
etapas — o modelo "erra menos" quando o processo fica explícito.

```
❌ "Qual o total da compra?" → resposta direta, mais sujeita a erro de cálculo
✅ "Pense passo a passo antes de dar a resposta final." → o modelo detalha cada etapa
```

## Exemplo em Python

Código completo: [`exemplos-python/2.2_few_shot_e_chain_of_thought.py`](exemplos-python/2.2_few_shot_e_chain_of_thought.py)

```python
prompt_few_shot = """\
Classifique o sentimento de cada avaliação como "positivo", "negativo" ou "neutro".

Avaliação: "Entrega rápida, produto exatamente como descrito."
Sentimento: positivo

Avaliação: "Chegou quebrado e o suporte não respondeu."
Sentimento: negativo

Avaliação: "Melhor compra que fiz esse ano, super recomendo!"
Sentimento:"""
```

Rode o script completo e compare as respostas com e sem `"Pense passo a passo..."` no
prompt matemático — normalmente a versão com CoT mostra o cálculo explícito e chega ao
resultado correto de forma mais consistente.

## Quando usar cada técnica

| Situação | Técnica recomendada |
|---|---|
| Classificação com categorias específicas do seu domínio | Few-shot |
| Extração de dados em formato exato (ex: JSON customizado) | Few-shot |
| Problemas de matemática, lógica, múltiplas etapas | Chain-of-thought |
| Decisões que envolvem comparar várias opções | Chain-of-thought |
| Tarefa simples e comum (resumir, traduzir) | Nenhuma das duas — zero-shot direto já funciona bem |

## Pontos-Chave

✅ Few-shot mostra o padrão esperado com exemplos, em vez de só descrevê-lo em palavras.
✅ Chain-of-thought pede para o modelo expor o raciocínio antes da resposta final.
✅ Ambas as técnicas consomem mais tokens (custo maior) — use quando o ganho de precisão compensar.
✅ Para tarefas simples e comuns, zero-shot direto costuma já ser suficiente.
