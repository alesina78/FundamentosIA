# 1.1 — O que são LLMs e como funcionam

> **LLM (Large Language Model)**: um modelo estatístico treinado em grandes volumes de
> texto para prever, token a token, qual é a continuação mais provável de uma sequência.

## A ideia central: previsão do próximo token

Um LLM não "sabe" fatos como um banco de dados nem "raciocina" como um humano. Na base, ele
faz uma coisa repetidamente: dado um texto de entrada, calcula a probabilidade de cada
palavra/pedaço de palavra (token) possível ser o próximo, escolhe um, anexa ao texto, e
repete o processo.

```
Entrada: "O céu é"
Modelo calcula probabilidades:  azul (62%), lindo (9%), enorme (3%), ...
Escolhe: "azul"
Nova entrada: "O céu é azul"
Repete...
```

Esse processo simples, aplicado em escala (bilhões de parâmetros, treinado em trilhões de
tokens), produz comportamentos que parecem raciocínio, sumarização, tradução e código —
mas é sempre, no fundo, predição de sequência.

## Como um LLM chega a esse comportamento

1. **Pré-treinamento**: o modelo aprende padrões de linguagem lendo enormes quantidades de
   texto público (livros, código, sites), apenas prevendo o próximo token.
2. **Fine-tuning / RLHF**: o modelo é ajustado com exemplos curados e feedback humano para
   seguir instruções, ser útil e evitar respostas nocivas.
3. **Inferência**: quando você usa o modelo (via chat ou API), ele só está aplicando o que
   aprendeu — não está aprendendo em tempo real com sua conversa.

## Exemplo em Python — chamando um LLM pela API

Código completo: [`exemplos-python/1.1_chamada_basica.py`](exemplos-python/1.1_chamada_basica.py)

```python
client = anthropic.Anthropic()  # lê ANTHROPIC_API_KEY do ambiente
response = client.messages.create(
    model="claude-haiku-4-5",
    max_tokens=100,
    messages=[{"role": "user", "content": "Explique em uma frase o que é um LLM."}],
)
print(response.content[0].text)
```

Cada chamada é **stateless**: o modelo não se lembra de chamadas anteriores. Para manter
contexto de uma conversa, você reenvia o histórico inteiro a cada chamada — é isso que os
apps de chat fazem por trás dos panos.

## Explorando outros modelos além do Claude

Este curso usa a API da Anthropic como referência, mas o conceito de LLM (predição de
próximo token) é o mesmo em qualquer modelo. Se você quiser explorar o ecossistema mais
amplo — modelos open-source, comparar arquiteturas, testar modelos menores que rodam
localmente — o [Hugging Face](https://huggingface.co/models) é o principal hub de modelos
da comunidade: um catálogo pesquisável com milhares de LLMs (e outros modelos de IA),
muitos com pesos abertos para download e uso local.

## Determinístico? Não exatamente

A geração é probabilística — o modelo amostra entre as opções mais prováveis (controlado
pelo parâmetro `temperature`). Por isso, a mesma pergunta pode gerar respostas ligeiramente
diferentes em execuções distintas.

| `temperature` | Comportamento |
|---|---|
| `0` | Quase determinístico, escolhe sempre o token mais provável |
| `0.7` (padrão comum) | Equilíbrio entre coerência e variedade |
| `1.0+` | Mais criativo/aleatório, maior risco de divagar |

## Pontos-Chave

✅ Um LLM prevê o próximo token com base em probabilidade, não "sabe" fatos como um banco de dados.
✅ Chamadas à API são stateless — o histórico de conversa precisa ser reenviado a cada chamada.
✅ `temperature` controla o quanto a geração é determinística vs. exploratória.
✅ Pré-treinamento ensina padrões de linguagem; fine-tuning/RLHF ensina a seguir instruções com segurança.
