# Módulo 8 — Boas Práticas e Uso Responsável

> Nível: Todos os níveis

## Objetivos de Aprendizagem

Ao final deste módulo, você será capaz de:

- Reconhecer cenários em que IA generativa NÃO deve ser usada.
- Identificar vieses e alucinações comuns e mitigá-los no fluxo de trabalho.
- Aplicar práticas básicas de privacidade e segurança de dados ao usar IA (o que não
  enviar para um provedor externo).
- Definir pontos de revisão humana obrigatória num processo que envolve IA.
