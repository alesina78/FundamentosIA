# Módulo 7 — SDD (Spec-Driven Development)

> Nível: Intermediário · A metodologia que você aplica dentro do harness do módulo 6.

## Onde este módulo se encaixa

O módulo 6 apresentou a ferramenta; este apresenta **o método de trabalhar com ela**. Um
harness executa o que você pede — a qualidade do resultado depende da qualidade do pedido, e
SDD é a disciplina de formular esse pedido.

Vale distinguir deste módulo o módulo 9, que volta ao mesmo terreno com outro recorte:

| Módulo | Pergunta que responde |
|---|---|
| **7 (este)** | Como se escreve uma spec boa, e como se vai dela ao código |
| **9** | Onde a spec entra no ciclo real de trabalho, ao lado de testes, revisão, documentação e CI |

## Objetivos de Aprendizagem

Ao final deste módulo, você será capaz de:

- Explicar o que é Spec-Driven Development e por que ele funciona melhor com IA do que
  "vibe coding" sem estrutura.
- Escrever uma especificação clara o suficiente para guiar um agente de codificação.
- Aplicar um fluxo spec → plano → implementação → verificação num projeto real.
- Reconhecer os riscos de pular a etapa de spec (retrabalho, escopo mal definido).
